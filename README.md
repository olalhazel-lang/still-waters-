# Stillwater — Yoga Studio

A calm, slow-paced yoga studio website designed for beginners and seasoned practitioners alike, featuring a weekly class timetable, tailored teaching philosophy, and a complimentary first-class invitation.

## Page Sections & Navigation
- **Classes (`#classes`):** Highlights slow-paced movement and breathwork classes held in an airy, calm space.
- **Weekly Timetable:**
  - **Mon & Wed:** Morning breath and movement (7:30 – 8:30 · All levels)
  - **Tue & Thu:** Mindful movement (2:00 – 3:30 · Beginners)
  - **Friday:** Fascia & Breath (4:30 – 5:30 · All levels)
  - **Saturday:** Heat-building flow (6:30 – 7:30 · Beyond basics)
- **Teachers (`#teachers`):** Focuses on small group sizes and adapting poses for beginners, tightness, or injury considerations.
- **First Visit (`#first-visit`):** Introduces a complimentary first class where mats and studio essentials are provided—visitors only need comfortable clothes and water.

## Built With
- HTML5
- CSS3

## Running Locally
1. Open the `Still.water` project folder in **Visual Studio Code**.
2. Launch `index.html` using **Live Server** (or open it directly in your browser).
